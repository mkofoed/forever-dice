# Forever Dice

Roll a random race, class and body type for your next World of Warcraft: Forever character.

- Only valid race/class combinations from WoW Forever (including Skyborne High Order and Windshaper)
- Exclude any race, class or body type; options that become impossible are marked as unavailable
- Plain static HTML, CSS and JavaScript in a single `index.html`

Live: https://mkofoed.github.io/forever-dice/

Fan-made and not affiliated with Blizzard Entertainment.
